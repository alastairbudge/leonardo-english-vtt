# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is a content repository containing WebVTT (.vtt) subtitle files for the "English Learning for Curious Minds" podcast by Leonardo English. There is no application code, build system, or tests.

## File Structure

- **ELFCM###.vtt** - Main episode subtitles (ELFCM001.vtt through ELFCM608.vtt)
- **ELFCMBONUS###.vtt** - Bonus episode subtitles
- **ELFCMAEE.vtt** - Special episode
- Other .vtt files - Miscellaneous subtitle files

## VTT File Format

Files follow standard WebVTT format generated by Descript:
```
WEBVTT

NOTE
This file was generated by Descript <www.descript.com>

00:00:04.109 --> 00:00:10.070
Subtitle text here.
```

## Naming Convention

Episode files use the format `ELFCM` + zero-padded 3-digit number (e.g., ELFCM001, ELFCM042, ELFCM608).

## Common Tasks

- Adding new episode: Create `ELFCM{next_number}.vtt` following the naming convention
- Files are typically committed in small batches by episode number ranges
